# WinRM Fleet Console

Полноэкранный TUI-клиент для управления парком Windows-машин через WinRM.
Он рассчитан на Windows PowerShell 5.1 и PowerShell 7 под Windows.

## Быстрый старт

```powershell
cd C:\projects\powershell\powershellScripts\WinRM
.\Start-WinRMTui.ps1
```

Если политика выполнения блокирует локальные скрипты, запускайте из уже
доверенной сессии PowerShell или используйте подходящую политику вашей
организации. Для изолированного/переносимого состояния:

```powershell
.\Start-WinRMTui.ps1 -StorePath D:\Admin\winrm-state
```

По умолчанию данные находятся в `%LOCALAPPDATA%\WinRMTui`:

- `config.json` — профили сетей, blacklist и таймауты;
- `inventory.json` — машины, endpoint’ы, группы, теги и инвентаризация;
- `logs\audit.jsonl` — журнал запусков и результаты каждой машины;
- `downloads` — стандартная папка сбора файлов;
- `scripts` — пользовательская библиотека `.ps1`.
- `addons` — доверенные пользовательские аддоны PowerShell.

Учётная запись по умолчанию и пароли не сохраняются. Перед каждой удалённой операцией
TUI заново просит логин и пароль. Для одной выбранной машины достаточно ввести короткий логин:
клиент подставит вычисленное имя компьютера и передаст `COMPUTER\login`.
Клиент не меняет `TrustedHosts`, не отключает
проверку HTTPS-сертификатов и не настраивает удалённые машины автоматически.

## Возможности и клавиши

| Клавиша | Действие |
| --- | --- |
| `D` | Выбрать вычисленный `/24` wildcard сетевого адаптера или пункт `[custom]` |
| `N` | Добавить/удалить профиль сети |
| `Tab`, `Shift+Tab` | Переключить верхнюю вкладку Fleet/аддона |
| `M` | Добавить известный DNS/IP endpoint вручную |
| `F` | Фильтр инвентаря |
| `Space`, `A`, `Esc` | Отметить хост, отметить все видимые, очистить выбор/фильтр |
| `I` | Собрать свежую системную инвентаризацию |
| `X` | Выполнить однострочную команду или локальный `.ps1`, при необходимости передать JSON `ArgumentList` |
| `L` | Выполнить скрипт из встроенной/пользовательской библиотеки |
| `Enter` | Открыть командную оболочку в постоянной `PSSession` на одной машине; `exit` возвращает в TUI |
| `U`, `O` | Передать файл/каталог или собрать файлы с машин |
| `P` | Перезагрузка/выключение с отдельным подтверждением и задержкой 60 секунд |
| `G`, `T` | Назначить выбранным машинам группы или теги |
| `B` | Управлять blacklist (имя/IP wildcard или CIDR) |
| `H`, `J` | Карточка машины и последние события аудита |
| `E`, `V` | Экспорт/импорт CSV |
| `S`, `R` | Таймауты/throttle/DNS и перечитать состояние с диска |
| `?`, `Q` | Помощь и выход |

Если есть отмеченные машины, операция выполняется над ними. Если отметок нет —
только над текущей строкой. Поэтому массовый запуск на всех устройствах делается
явно: примените фильтр, нажмите `A`, затем `X` или `L`.

Примеры фильтров (условия через пробел объединяются как AND):

```text
office
group:Office status:Connected
tag:prod os:Server !tag:test
ip:192.168.10.* disk:<10
```

Встроенные диагностические сценарии находятся в `scripts`: обзор системы,
крупнейшие процессы, критические события за сутки и проверка ожидаемой
перезагрузки. Любой другой `.ps1` можно положить в пользовательский каталог
`scripts` в хранилище и запускать клавишей `L`.

## Автоматизация без TUI

Слой данных доступен как обычный модуль:

```powershell
Import-Module .\WinRM.Manager.psd1
$store = Initialize-WinRMStore
$config = Get-WinRMManagerConfig
$hosts = Get-WinRMInventory
$servers = Find-WinRMInventory $hosts 'group:Servers status:Connected' $config.Blacklist
Export-WinRMInventoryCsv $servers .\servers.csv
```

Транспортные функции находятся в `WinRM.Tools.psm1`: `Invoke-WinRMBatch`,
`New-WinRMTargetSession`, `Invoke-WinRMFileTransferTarget` и
`Invoke-WinRMFileTransferBatch`. `Find-WinRM.ps1` можно использовать отдельно.

## Аддоны

Аддоны — доверенные модули PowerShell без sandbox и списка разрешений. Они работают
с правами процесса TUI и могут импортировать модули, запускать и устанавливать
сторонние программы, обращаться к сети, менять состояние приложения и полностью
управлять консольным UI. Устанавливайте только код, которому доверяете.

Встроенные аддоны находятся в `addons`, пользовательские — в
`%LOCALAPPDATA%\WinRMTui\addons`. После добавления каталога нажмите `R`, чтобы
обновить верхние вкладки, затем переключайтесь между ними клавишами `Tab` и
`Shift+Tab`.
Корневой TUI обнаруживает `addon.psd1`, загружает указанный модуль и передаёт ему
живой контекст приложения, включая корневой `SessionState`. Новый аддон не требует
добавления отдельной клавиши или изменения `Start-WinRMTui.ps1`. Полный контракт и
пример манифеста описаны в `addons\README.md`.

В комплект входит `Domain Watch`. Он открывает постоянные WinRM-сессии к выбранным
компьютерам, каждые три секунды сопоставляет `Get-NetTCPConnection` с
`Get-DnsClientCache` и выделяет жёлтым домены из watchlist. `Space` переключает все
соединения/только совпадения, `W` редактирует список, `R` обновляет данные. Личный
список хранится в `%LOCALAPPDATA%\WinRMTui\addon-data\domain-watch\watchlist.json`.
Во вкладке Domain Watch `Tab` и `Shift+Tab` передают управление следующей или
предыдущей вкладке. Открытые сессии и состояние таблицы сохраняются при переключении
на Fleet и закрываются только при завершении всего приложения.

## Безопасность операций

- Перед скриптами, передачей файлов и питанием TUI показывает подтверждение.
- `Esc` останавливает локальную операцию, но уже начавшиеся удалённые изменения
  откатить невозможно; это отражается в аудите.
- Во время экрана выполнения обрабатывается только `Esc`; остальные нажатия
  отбрасываются и не срабатывают после завершения операции.
- Командная оболочка форматирует объекты на удалённой машине и согласует OEM-кодировку
  Windows для корректного вывода `dir`, `taskkill`, `PsExec` и других native-команд.
- Результат `WSManConfirmed` означает обнаруженный WS-Management endpoint, но
  не успешную аутентификацию.
- При работе по IP в workgroup заранее настройте допустимый способ
  аутентификации согласно политике организации.
- `Init-WinRM.ps1` и `RemoveWinRmLimit.ps1` оставлены отдельными bootstrap-
  скриптами для привычного запуска через `iex(irm ...)`.

```powershell
.\tests\Test-WinRMTui.ps1
```

Тесты используют временное локальное хранилище и mock/loopback-проверки; к
машинам из реальной сети не подключаются.
